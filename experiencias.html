atuei como professor do projeto CRIAR JOGOS no Colégio Estadual Barbosa Rodrigues ensinando fundamentos básicos de programação direcionada a criação de jogos
o projeto CRIAR JOGOS é um projeto de formação gratuita em desenvolvimento de games para jovens a partir de 12 anos, que envolve ações educativas ao trabalhar tecnologia e game design de forma simples e acessível. Mochilão CESUCA (2024 - 2026)

Liderei e coordenei o grupo de voluntários como palestrante titular e organizei os workshops. Elaborei plano de ensino adaptando lógica de programação para adolescentes de 14 a 16 anos. Ministrei aulas utilizando Code Hour com Minecraft (2024) e MIT App Inventor (2025). Mediei conflitos e solucionei problemas logísticos e de infraestrutura durante os eventos.
O Mochilão CESUCA é um projeto de extensão anual que aproxima o ensino superior da comunidade escolar. Alunos da faculdade ministram workshops de 45 minutos para turmas do ensino médio. O desafio é ensinar um conceito da área de forma intuitiva, dinâmica e compreensível para jovens que estão começando a explorar o universo acadêmico e profissional.
