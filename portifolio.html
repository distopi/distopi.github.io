Chat

Chat local baseado em CMD

Este programa é um chat em lote (batch script) para Windows que simula um ambiente de conversa entre usuários utilizando arquivos de texto como histórico. Ao ser executado, ele cria automaticamente um segundo script (read.bat) responsável por exibir continuamente as mensagens registradas nos arquivos log.cdat (entradas de participantes) e mes.cdat (mensagens enviadas). O usuário informa seu nome, que é registrado no log com data e hora, e então uma nova janela é aberta para exibir as mensagens em tempo real. Em seguida, o programa entra em um loop onde o usuário digita suas mensagens, que são salvas no arquivo de mensagens com o nome do remetente, proporcionando uma troca de mensagens simples entre múltiplos usuários que acessam os mesmos arquivos em um diretório compartilhado.

Mages of the hill

Mages of the hill

Desenvolvi um site como projeto de conclusão de módulo no curso do Senac, que simula uma revista digital dedicada ao universo de RPG. O projeto foi construído com foco nos princípios de Interação Humano-Computador (IHC), priorizando uma navegação intuitiva, hierarquia visual clara e acessibilidade para proporcionar uma experiência envolvente aos leitores. A interface organiza conteúdos como matérias, resenhas e entrevistas de forma responsiva, adaptando-se a diferentes dispositivos, e utiliza elementos interativos que refletem a identidade temática da revista, unindo usabilidade e imersão no contexto dos jogos de interpretação.

Qr code

QR code com API

Desenvolvi um site utilitário que gera dinamicamente um código QR para direcionar visitantes ao meu portfólio. O projeto consome uma API externa que produz a imagem do QR code a partir de qualquer URL fornecida, permitindo flexibilidade de uso. Para integrar visualmente o código ao design da página, apliquei um filtro CSS que torna as áreas brancas da imagem transparentes, fazendo com que o QR code se sobreponha de forma harmônica ao fundo, resultando em uma apresentação limpa e personalizada.

Portifolio

portifolio

Meu portfólio pessoal é um projeto em constante evolução, desenvolvido com o objetivo de explorar e testar novas tecnologias web. Atualmente, o site adota uma identidade visual retrô, simulando monitores de tubo com efeitos de scanlines e fósforo, enquanto organiza o conteúdo em seções que imitam janelas de um sistema operacional, proporcionando uma experiência nostálgica e interativa. Cada atualização busca incorporar técnicas modernas de front-end, como CSS Grid, Flexbox, animações personalizadas e abordagens responsivas, mantendo o ambiente como um laboratório criativo para experimentação e aprimoramento contínuo.
